# Verdict: Catalyst (`ssh catalyst`)

## Justification

**Catalyst is the instrument through which code becomes effect.**

If code is the arcane, then source files are spells: inert text that does nothing until something channels it. In the Souls lineage this is the exact role of a Catalyst. A sorcerer does not carry power inside the staff; the Catalyst is the focus through which their intent becomes a cast. A developer's laptop plays the same part. The knowledge, repositories and ideas belong to me, and the machine is the focus that turns them into running software.

The chemistry meaning says the same thing from the other side. A catalyst accelerates a reaction without being consumed by it. The machine does not author the work, but it shortens the distance between intent and result, and it is still there, unchanged, for the next project. That durability is why it earns a place as the daily carry.

**One word, two readings that agree:**

| Reading | Meaning | What it says about the device |
|---|---|---|
| Arcane (Demon's Souls / Dark Souls) | The focus a sorcerer casts through | Code is magic; the laptop is how it is cast |
| Chemical (Era 1) | An agent that speeds a reaction and survives it | The laptop accelerates work and persists across projects |

## Fit in the fleet

- **Era 1 (Xenon, Beryl):** Chemistry survives, recast from element to process.
- **Era 2 (Firelink, Majula, Emerald):** The Souls lineage survives. Catalysts are the sorcerer's tool in the same games that gave the home servers their names.
- **Luminous:** Luminous was the mage. Catalyst is what a mage casts through, so the successor is the instrument of its predecessor.
- **Era 3:** The first device with no game attached. The arcane motif moves from play to craft, which makes it the bridge into creation.

## Short-form version (for the document)

> **Catalyst.** In the Souls games, the focus a sorcerer casts through; in chemistry, the agent that accelerates a reaction and is never consumed. If code is the arcane, this machine is the instrument that turns written spells into working effect, carried daily, unchanged by the work it enables. Successor to Luminous the mage, and the first device of the creation era.
